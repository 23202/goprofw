# 03 · 8K60 到底被谁限制

问题：为什么某台机器拍不了 8K60p。

## 路径一：Linux 配置（已排除）

`usr/local/gopro/etc/<model>/settings.json` 里，**只有 65 号机型**同时有 `8K` 和 `8K 4:3`：

```
setting id=2 Resolution
  31 = 8K        40 = 8K 4:3
  100/113 = 5.3K   1/112 = 4K   4/111 = 2.7K   9/110 = 1080   43 = 1080 4:3

setting id=3 Frames Per Second
  5 = 60    6 = 50    8 = 30    9 = 25    10 = 24
  1 = 120   2 = 100   0/13/15/18/19/20 = 200~960
```

**JSON 里没有任何"8K 只能 30p"的规则**，反而有一条专门为 8K60 写的：

| filter | 条件 | 效果 |
|---|---|---|
| #52 | `Resolution=31` 且 `FPS∈{5,6}` | 禁用部分镜头/数字镜头选项（说明 8K60 是被支持的，只是限镜头） |
| #90 | `Sub Mode=Looping` 且 `Resolution=31` | FPS 去掉 60/50 |
| #87 | `Framing=9:16` | FPS 去掉 60/50（竖拍没有 8K60） |

黑名单的执行者是 `usr/lib/libgpBlacklistHandler.so`：

```
BHBlacklist::optionInBlacklist
BHBlacklist::getBlacklistedOptionsMap
BHCriteria::settingOptionExist / statusOptionExist
```

## 路径二：运行时能力表（真正的门）

`usr/lib/libgpCtrlD.so`：

```
gpc_video_set_res / gpc_video_set_fps / gpc_video_set_fov
gpc_video_get_res_fps_fov / gpc_video_get_current_res_fps_shutter
GPCONTROL_GET_CAMERA_CAPABILITIES  →  "camera-capabilities/v1.0"
日志："invalid res_count %d" / "No capabilities found for model number %d"
```

调用链：

```
App / HTTP → gpControlD → libgpCtrlD → IPC(mbox) → RTOS
```

RTOS 返回 (res, fps, fov) 能力表，Linux 只是把它和 settings.json 的选项取交集后显示。

反证：64 号机型的 JSON 里理论上也列着 8K@100/120，但那是一台 360° 双镜头机（`Camera Mode: Single Lens / 360°`），物理上不可能——说明 JSON 只是"可枚举壳"，上限由 RTOS 给。

## 路径三：机型识别

`libgpCtrlD.so` 的 `gpc_state_get_model_number()`：

```
csi_get("CSI_MODEL_NUMBER")            // RTOS 提供的键值服务
失败回退: grep "CSI_MODEL_NUMBER" /tmp/fuse_b/conf.json | cut -d ":" -f 2 ...
日志: "model_number, %d" / "csi model_number lookup failed"
      "loaded model_number from config: %d"
      "failed to read model_number from config, cannot determine model_number"
```

机型 → 能力 schema（`getCameraCapabilitiesSchemaVersion`，0x1427D0）：

| model | schema 变量 |
|---|---|
| 0x45 (69) | `sandbar_capabilities_schema_version` |
| 0x47 (71) | `sandbar_lite_capabilities_schema_version` |
| 0x49 (73) | `blackbird_capabilities_schema_version` |
| 0x4A (74) | `sandbox_capabilities_schema_version` |
| 其余 | 默认 |

## 结论

- Linux 用户层**没有**硬编码的 8K60 禁止，翻遍 rootfs 找不到"if 8K then 30fps"。
- 能力表由 RTOS 给，RTOS 在 p2（唯一加密分区）里。
- 因此：改 settings.json 可以让界面"多出"8K60，但 RTOS 不认就会报错或回落。
